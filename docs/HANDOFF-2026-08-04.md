## Mistakes made this session — do not repeat

1. **Semrush v4 auth is `Authorization: Apikey <key>`, NOT `Bearer`.** I burned several rounds on
   `Bearer` and misdiagnosed a valid key as invalid. Base URL is
   `https://api.semrush.com/apis/v4/`. A `403` means recognised-but-not-entitled; a `404` means the
   path does not exist. That distinction is how to tell them apart.
2. **I overstated the GSC finding.** I told Mark Step 4 would "destroy real traffic." It would risk
   ~222 clicks/year. The classifier was directionally right. Do not alarm him; give him the
   aggregate before the anecdote.
3. **Removing `typescript` left the project with no type checking.** Node strips types without
   validating them. A real Notion-SDK union bug shipped and was caught only by an explicit
   `tsc --noEmit`. **Run `npm run check` before committing.**
4. **`.gitignore` had a bare `.env*`** which silently ignored `.env.local.example`. Fixed with
   `!.env.local.example`. Watch for that pattern.
5. **Node applies the LAST `--env-file` listed**, so `.env.local` must come after the shared file
   to override it. I assumed the opposite; testing corrected it.

## Do not do these

- **Never re-run `site-audit/build_disposition_map.py`.** It is retired as a generator.
  `state/pages.csv` now holds human review decisions; re-running overwrites them with heuristics.
- **Never re-run `scripts/flag-gsc-review.ts --apply`** without `--force`. It aborts on purpose —
  re-flagging cleared rows would destroy deliberate decisions.
- **Never merge measured and estimated traffic into one figure.** Conflating them is how the 14x
  error stayed invisible for months.
- **Nothing writes to Notion.** Read-only, task database only.
